# Three-Stage Compilation with Architecture Lowering

Foundation separates compilation into three distinct stages: Blueprint to **Semantic IR** (pure domain), Semantic IR to **Architecture IR** (structural pattern lowering driven by the **Build Profile**), and Architecture IR to target language code. Meanwhile, tactical behavioral guarantees (idempotency, caching, retries) are declared inline as **Traits** in the Blueprint. Coupling structural patterns (like Hexagonal or Layered CRUD) directly into Blueprint files would require rewriting domain specifications whenever an application's architecture evolves, whereas separating structural lowering in the middle-end allows the same Blueprint to be recompiled into entirely different architectural topologies by changing the Build Profile.
